# M20 Item System

## Muc dich

Dat chuan cho tat ca vat pham xuat hien trong game.

## Item Categories

- material
- tool
- consumable
- crafting component
- collectible
- cosmetic
- ticket / token
- relic / special item

## Required Fields

Moi item nen co:

- item id
- display name
- category
- rarity
- source
- sinks / uses
- stack rule
- tradable hay khong
- seasonality neu co

## Design Rules

- Moi item phai co ly do ton tai.
- Item khong co use sau 2-3 loop nen duoc cat bo hoac merge.
- Khong de inventory ngap item rac vo nghia.
