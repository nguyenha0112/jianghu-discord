# M01 Economy Core

## Muc dich

Xac lap economy loop cot loi cua server va cach gia tri di chuyen giua thoi gian, hanh dong, tai nguyen va phan thuong.

## Core Loop

`Time -> Action -> XP -> Profession Progress -> Materials -> Crafting / Exchange -> Xu -> Ngoc -> Aspirational Rewards -> Continued Play`

## Economy Components

### Sources

- daily
- profession actions
- onboarding quest
- weekly objective
- event phan thuong
- guild milestone

### Transformations

- refine material
- combine item
- craft tool
- convert resource theo cong thuc
- upgrade item

### Sinks

- mua tool
- phi che tao
- cosmetic shop
- ticket / token event
- reroll / repair / enhancement
- guild contribution

### Aspirations

- collection
- title
- rare cosmetic
- monthly reward eligibility
- leaderboard theo mua

## Design Rules

- Source phai cham hon sink o tang cao de tranh inflation.
- Item trung gian phai co gia tri su dung, khong chi dung de doi tien.
- Premium reward phai di qua nhieu lop effort, khong den truc tiep tu daily.
- Moi he thong moi them vao phai khai bao ro source, sink va exploit risk.

## Retention Logic

Economy khong chi de "kiem tien" ma de tao ly do quay lai:

- hom nay co daily
- hom nay can farm them material
- hom nay du craft mot mon do moi
- hom nay sap dat moc title / collection

Neu economy chi con mot hanh dong toi uu duy nhat, he thong se tro nen nha chan va de bi pha vo.
