# M22 Drop Table

## Muc dich

Dat quy tac xay dung bang roi vat pham cho nghe nghiep, event va reward.

## Rules

- Drop table phai minh bach trong noi bo.
- Rare drop phai co enough attempts expectation hop ly.
- Khong de user cam thay "khong bao gio co the ra".

## Table Design Layers

- guaranteed layer
- weighted common layer
- rare bonus layer
- jackpot / relic layer

## Safety Rules

- reward hiem khong den tu single low-effort action qua de
- can theo doi drop rate thuc te sau van hanh
